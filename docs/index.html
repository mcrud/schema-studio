Build CRUD from a schema, not a terminal.

mcrud/crud gives Laravel projects a browser-based schema builder that generates CRUD, translations, dashboards, roles and permissions.

View on GitHub

Schema Builder

Define fields, database types, nullable columns, unique indexes and default values in the GUI.

Localized UI

Generate English and Arabic translation files with every CRUD resource.

Secure by default

Create action-level permissions and seed them into roles with Spatie Permission.

Install

composer require mcrud/crud
php artisan vendor:publish --tag=crud-config
php artisan vendor:publish --provider="Spatie\Permission\PermissionServiceProvider" --tag="permission-migrations"
php artisan migrate

Laravel package discovery registers the package automatically. Open /crud-generator in your application to begin.

Generate a resource

  1. Enter a resource name such as Product.
  2. Add schema fields and select each column’s type, nullable/unique rules and optional default value.
  3. Select English, Arabic, or both for generated translation files.
  4. Select the actions to protect and enter role names such as admin, editor.
  5. Optionally choose Also create Dashboard, then generate.

What is generated?

Laravel code

Migration, Eloquent model, resource controller, route registration and Blade index/form views.

Authorization

A permission seeder creates resource permissions and assigns them to the selected roles. Controllers protect each selected action.

Localization

Language files are placed in lang/en and/or lang/ar, and generated views use Laravel’s __() helper.

Seed permissions

For a generated Product resource, run its generated seeder:

php artisan db:seed --class=ProductPermissionSeeder

Configuration & safety

Publish configuration with the install command above. In production, protect the builder itself by adding auth (and your admin middleware) to middleware in config/crud.php. The generator intentionally refuses to overwrite existing files.
